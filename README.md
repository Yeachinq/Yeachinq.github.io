# 地牢回响

2.5D 俯视角地下城肉鸽游戏，纯前端、无素材、无依赖。

目前完成到**第三步**：大厅 → 房间式地牢（可探索）。战斗还没做。

## 怎么跑

双击 `index.html` 打开大厅，点中间的传送门进入地牢。

**大厅和地牢在同一个页面里**，切换靠显示/隐藏，不跳转——所以在手机上先全屏再进地牢，全屏状态会一路保持，不会白屏。

手机竖屏会提示横屏。整个游戏不需要联网，也不需要构建。

## 现在能玩什么

**大厅**

- 石砖房间、两支跳动的火把、旋转的漩涡传送门、浮尘、暗角
- 点击传送门 → 白光扩散 → 进入地牢

**地牢**

- 每次进入随机生成 **7 个正方形石室**，房间之间**没有走廊**，只靠墙上的门相连
- 走到门里就切换到相邻房间（黑屏一闪），进入时站在对面那扇门内
- 每间石室有火把、地面碎石，**部分房间会有对称排列的障碍墙**（左右 / 上下 / 中心对称），外墙之外是深色岩层
- 右下角小地图显示已探索的房间：**出生房绿色、楼梯房黄色**、其他灰色，当前所在房间用青色描边；地图上方有 **红点 + 数字**，表示本层还有几间刷怪房没清空（清完自动消失）
- 角色有一把手枪：**基础伤害 15**，**自动朝离自己最近的小怪开枪**（只定方向，子弹不追踪；没有小怪时朝角色面向射，角色朝向不会被强制转向），子弹撞墙会消失并留下弹着点，可以穿过门洞
- 按住攻击键会按射速连发（**每秒 2 发**，间隔 0.5 秒），没有弹夹和弹药限制
- 除起始房间外，**每间房刷 3 波怪，每波 2–4 只（整间共 6–12 只）**；**推门进去先落栅栏锁门，停 0.5 秒才开始刷第一波**，一波清完停 1 秒再刷下一波；每次刷怪前都有 **0.55 秒地面预警**（红光圈 + 上升粒子），随后怪物**从地面破口升起、淡入成形**（下方被地面裁掉，像从地里钻出来）；三种怪**随机混编**（近战 45% / 远程 35% / 爆炸 20%）
  - **近战怪**：血量 50、伤害 10，移动速度是主角的 30%（21），贴近后停住蓄力 0.45 秒再挥击，蓄力时闪红光，可以躲
  - **弓箭手**：血量 80、伤害 15，不主动靠近，会**随机游走**（走 0.4–1.3 秒、停 0.3–0.9 秒，撞墙自动换向）；主角贴近到 64px 内会后退（拉弓时 20% 速度、平时 30%）；**全房间可射**，每 2 秒一轮：先拉弓 0.4 秒（有瞄准线和蓄力光点），再射出**速度 120 的箭**（手枪子弹 200 的 60%）
  - **爆炸怪**：血量 70、伤害 35，**速度是主角的 70%（49）**，贴近 30px 后点火，**引信 1.3 秒**（身上绿白急闪、地上浮出爆炸范围圈）；蓄力时**不停止，仍以 30% 速度（14.7）缓慢逼近**；引信期间跑出 70px 会熄火；爆炸半径 45px，**只伤玩家、隔墙无效**；被子弹打死**不会自爆**
- 房间里还有怪、或者还有没刷出来的波次时，**门口落下铁栅栏**，三波全清才开
- 被咬中扣 10 血并**红屏闪烁 + 0.8 秒无敌**；血量归零弹出「你倒下了」，回到大厅后重开第一层
- **经验与升级**：击杀给经验（近战 5 / 弓箭手 8 / 爆炸怪 7），**清空一间房额外 +10**；经验**跨楼层保留、死亡清零**；升级曲线 **35 / 49 / 63 / 77…**（每级 +14，一层大约能升 3–4 级）；升级时游戏暂停并弹出**三选一强化卡**（强化弹头 +9 伤害 / 快速装填 -12% 射击间隔 / 轻快步伐 +12% 移速 / 强健体魄 +45 生命上限并回 45 / 穿甲弹 子弹多穿透 1 个 / 急救包 回 80 血），选完立刻恢复战斗；`Lv` 和经验条显示在血条下方
- 最远的房间有楼梯，**这间房不会刷怪**；站到楼梯上会弹出「下到第 N 层」按钮，但**必须先把本层所有刷怪房间清空**——没清完时按钮是置灰的，显示「还有房间未清理」，点了也不会下楼；清空后按钮亮起，点一下重新生成新的一层，楼层数 +1
- 每一层都用同一套规则生成（7 个房间、同样的门逻辑），目前层数只影响显示，难度还没有递进
- 左上角只显示**层数**和 **HP / EP 两条状态条**（基础值都是 100，目前没有东西会消耗它）；右上角齿轮打开设置菜单（继续游戏 / 全屏 / 返回大厅），打开时游戏暂停，`Esc` 关闭

## 操作

| 设备 | 操作 |
| --- | --- |
| 键盘 | `WASD` 或方向键移动，`J` / `空格` 射击（按住连发） |
| 鼠标 | 按住左键射击 |
| 手机 | 左下角**固定摇杆**移动，右下角**攻击键**射击，按住连发 |

## 技术说明

- 内部画布**高度 208**（宽度随窗口比例变化），像素放大不糊。
- 每个房间是 **14×14 格**（14px 一格 = 196×196 像素），边界一圈墙，门开在四面正中（两格宽）。
- 房间始终完整显示在一屏内，所以「地图变大」的表现是：**格子变多、角色相对变小**，而不是镜头拉远。
- 房间布局：从起点开始，每次随机挑一间已存在的房间往外扩一格，共 7 间；两个房间相邻就互相开门，所以布局天然连通。
- 障碍物：约 45% 的房间不放；其余的随机选一种对称方式（左右 / 上下 / 中心对称），在**中央十字外侧的环带（第 4–9 行/列）**放 1×1 或 2×2 的墙块，不贴墙边；**整间总格数控制在 3–8 格**。第 6、7 行和第 6、7 列组成的「十字」永远留空，保证出生点、楼梯和四扇门都走得通。
- 切换房间不是同一个场景里移动，而是**换一张房间地图**，把角色放到对面门口。切换时有一层黑色闪屏盖住瞬移。
- 大厅/地牢是同一个文档里的两个全屏图层，用 `hidden` 切换；未激活的那个图层会跳过绘制，省电。
- 2.5D：墙有顶面 + 正面、墙脚有接触阴影、物件按底边 Y 排序；**角色固定画在最上层，火把在地图之上、角色之下**；**门口图案属于地面细节，画在最底层**（站在门口的怪和角色会把它压住）。
- 光照只有火把：一张暗色遮罩，用 `destination-out` 在火把位置挖洞；角色本身不发光。
- **四面墙各 2 支火把**共 8 支；那一面有门时，两支会挪到门的两侧（列 5 / 8），没有门就对称放在墙中段（列 3 / 10）。

## 已知限制

- 正方形房间在横屏上两侧会留出深色岩层，这是「房间必须是正方形」的几何结果；想填满屏幕只能把房间做成横向长方形
- EP（能量）目前没有用途，也没有技能系统
- 手机摇杆手感没在真机上验证过
- 没有任何音效
