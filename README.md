# 地牢回响

2.5D 俯视角地下城肉鸽游戏，纯前端、无素材、无依赖。

目前完成到**第三步**：大厅 → 房间式地牢（可探索）。战斗还没做。

## 怎么跑

双击 `index.html` 打开大厅，点中间的传送门进入地牢。

**大厅和地牢在同一个页面里**，切换靠显示/隐藏，不跳转——所以在手机上先全屏再进地牢，全屏状态会一路保持，不会白屏。

手机竖屏会提示横屏。整个游戏不需要联网，也不需要构建。

## 现在能玩什么

**大厅**

- 石砖房间、两支跳动的火把、旋转的漩涡传送门、浮尘、暗角
- 点击传送门 → 白光扩散 → 进入地牢

**地牢**

- 每次进入随机生成 **7 个正方形石室**，房间之间**没有走廊**，只靠墙上的门相连
- 走到门里就切换到相邻房间（黑屏一闪），进入时站在对面那扇门内
- 每间石室有火把、地面碎石，外墙之外是深色岩层
- 右下角小地图显示已探索的房间，当前房间高亮
- 最远的房间有楼梯；**站到楼梯上会弹出「下到第二层」按钮**，点一下就重新生成新的一层，楼层数 +1
- 每一层都用同一套规则生成（7 个房间、同样的门逻辑），目前层数只影响显示，难度还没有递进
- 左上角显示房间序号；右上角齿轮打开设置菜单（继续游戏 / 全屏 / 返回大厅），打开时游戏暂停，`Esc` 关闭

## 操作

| 设备 | 操作 |
| --- | --- |
| 键盘 | `WASD` 或方向键移动 |
| 手机 | 左下角**固定摇杆**，手指按住底座拖动（触屏才显示） |

## 技术说明

- 内部画布**高度 208**（宽度随窗口比例变化），像素放大不糊。
- 每个房间是 **14×14 格**（14px 一格 = 196×196 像素），边界一圈墙，门开在四面正中（两格宽）。
- 房间始终完整显示在一屏内，所以「地图变大」的表现是：**格子变多、角色相对变小**，而不是镜头拉远。
- 房间布局：从起点开始，每次随机挑一间已存在的房间往外扩一格，共 7 间；两个房间相邻就互相开门，所以布局天然连通。
- 切换房间不是同一个场景里移动，而是**换一张房间地图**，把角色放到对面门口。切换时有一层黑色闪屏盖住瞬移。
- 大厅/地牢是同一个文档里的两个全屏图层，用 `hidden` 切换；未激活的那个图层会跳过绘制，省电。
- 2.5D：墙有顶面 + 正面、墙脚有接触阴影、物件按底边 Y 排序；角色固定画在最上层。
- 光照是一张暗色遮罩，用 `destination-out` 在角色和火把位置挖洞。

## 已知限制

- 正方形房间在横屏上两侧会留出深色岩层，这是「房间必须是正方形」的几何结果；想填满屏幕只能把房间做成横向长方形
- 没有战斗，所以「清房间」的流程还不存在
- 手机摇杆手感没在真机上验证过
