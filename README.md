# 地牢回响

2.5D 俯视角地下城肉鸽游戏，纯前端、无素材、无依赖。

目前完成到**第三步**：大厅 → 房间式地牢（可探索）。战斗还没做。

## 怎么跑

双击 `index.html` 打开大厅，点中间的传送门进入地牢。

**大厅和地牢在同一个页面里**，切换靠显示/隐藏，不跳转——所以在手机上先全屏再进地牢，全屏状态会一路保持，不会白屏。

手机竖屏会提示横屏。整个游戏不需要联网，也不需要构建。

## 现在能玩什么

**大厅**

- 石砖房间、两支跳动的火把、旋转的漩涡传送门、浮尘、暗角
- 点击传送门 → 白光扩散 → 进入地牢

**地牢**

- 每次进入随机生成 **7 个正方形石室**，房间之间**没有走廊**，只靠墙上的门相连
- 走到门里就切换到相邻房间（黑屏一闪），进入时站在对面那扇门内
- 每间石室有火把、地面碎石，**部分房间会有对称排列的障碍墙**（左右 / 上下 / 中心对称）；**出生房和楼梯房不刷障碍物**，外墙之外是深色岩层
- **右上角小地图**（在齿轮设置键左边）显示已探索的房间：**出生房绿色、楼梯房黄色**、其他灰色，当前所在房间用青色描边；地图下方有 **红点 + 数字**，表示本层还有几间刷怪房没清空（清完自动消失）
- 角色有一把手枪：**基础伤害 15**，**自动朝离自己最近的小怪开枪**（只定方向，子弹不追踪；没有小怪时朝角色面向射，角色朝向不会被强制转向），子弹撞墙会消失并留下弹着点，可以穿过门洞
- 按住攻击键会按射速连发（**每秒 2 发**，间隔 0.5 秒），没有弹夹和弹药限制
- 除起始房间外，**每间房刷 3 波怪，每波 2–4 只（整间共 6–12 只）**，**每往下 3 层每波数量上下限各 +1（封顶 10 只/波）**——第 4 层起 3–5 只、第 7 层起 4–6 只、第 19 层起 8–10 只；**推门进去先落栅栏锁门，停 0.5 秒才开始刷第一波**，一波清完停 1 秒再刷下一波；每次刷怪前都有 **0.55 秒地面预警**（红光圈 + 上升粒子），随后怪物**从地面破口升起、淡入成形**（下方被地面裁掉，像从地里钻出来）
  - **第 1–2 层**：近战 45% / 弓箭手 35% / 爆炸怪 20%
  - **第 3 层起**：近战 24% / 弓箭手 20% / 爆炸怪 14% / 冲刺兵 12% / 分裂怪 12% / 盾卫 10% / 炮台 8%
  - **近战怪**：血量 50、伤害 10，移动速度是主角的 30%（21），贴近后停住蓄力 0.45 秒再挥击，蓄力时闪红光，可以躲
  - **弓箭手**：血量 80、伤害 15，不主动靠近，会**随机游走**（走 0.4–1.3 秒、停 0.3–0.9 秒，撞墙自动换向）；主角贴近到 64px 内会后退（拉弓时 20% 速度、平时 30%）；**全房间可射**，每 2 秒一轮：先拉弓 0.4 秒（有瞄准线和蓄力光点），再射出**速度 120 的箭**（手枪子弹 200 的 60%）
  - **爆炸怪**：血量 70、伤害 35，**速度是主角的 70%（49）**，贴近 30px 后点火，**引信 1.3 秒**（身上绿白急闪、地上浮出爆炸范围圈）；蓄力时**不停止，仍以 30% 速度（14.7）缓慢逼近**；引信期间跑出 70px 会熄火；爆炸半径 45px，**只伤玩家、隔墙无效**；被子弹打死**不会自爆**
  - **盾卫**（第 3 层起）：血量 120、伤害 12，慢速推进；**从正面来的子弹减伤 60%**（15 伤只吃 6），侧面和背后照常吃满；冲刺、震荡波、盾反反弹的箭都不减伤；**被冲刺和震荡打出的眩晕时间 +50%**（冲刺 0.3→0.45 秒，震荡 1.3→1.95 秒）
  - **冲刺兵**（第 3 层起）：血量 55，平时慢速跟随；进入 **95px** 内蓄力 **0.5 秒**（地上画出冲锋方向），随后沿直线**猛冲 90px**，撞到扣 **15 血**，之后硬直 0.7 秒
  - **分裂怪**（第 3 层起）：血量 45、伤害 8，移动较快；**死亡时会裂成 2 只小分裂体**（15 血、速度 62、伤害 6），要留好收割的余量
  - **炮台**（第 3 层起）：血量 90，**固定不动**；主角进入 165px 内，每 2.2 秒朝**上下左右各射一发**慢速弹（10 伤害），弹可以被盾反弹回去
- 房间里还有怪、或者还有没刷出来的波次时，**门口落下铁栅栏**，三波全清才开
- 被咬中扣 10 血并**红屏闪烁 + 0.8 秒无敌**；血量归零弹出「你倒下了」，回到大厅后重开第一层
- **经验与升级**：击杀给经验（近战 5 / 弓箭手 8 / 爆炸怪 7），**清空一间房额外 +10**；经验**跨楼层保留、死亡清零**；升级曲线 **35 / 49 / 63 / 77…**（每级 +14，一层大约能升 3–4 级）；升级时游戏暂停并弹出**三选一强化卡（共 20 张）**，选完立刻恢复战斗；`Lv` 和经验条显示在血条下方
  - **输出**：强化弹头 +12 伤害 / 快速装填 -15% 射击间隔 / 高速弹 +30% 弹速 / 散弹 每次多射 2 发（向两侧各偏 10°）/ 穿甲弹 多穿透 1 个 / 暴击弹头 25% 概率双倍伤害
  - **生存**：强健体魄 +60 生命上限并回 60 / 急救包 回 100 血 / 吸血弹 每次命中回 2 血 / 再生 每秒回 2 血 / 不屈 受伤后无敌 +0.4 秒
  - **能量与技能**：能量扩容 EP 上限 +25 并回 25 / 快速充能 EP 回复 +25% / 节能 冲刺与震荡消耗 -25% / 锋利冲刺 冲刺伤害 +8 / 强化震荡 震荡伤害 +10
  - **其他**：轻快步伐 +15% 移速 / 老练 获得经验 +30% / 玻璃大炮 伤害 +50% 但生命上限 -25% / 重抽 放弃本次三选一，重新抽 3 张（不消耗升级次数）
- **EP（能量）现在有用了**：上限 100，每秒自动回复 8（消耗后有 0.5 秒延迟）；EP 不够时对应按钮会变灰
  - **冲刺**（25 EP）：朝移动方向（站住不动则朝面向）瞬移 46px，历时 0.16 秒，**冲刺期间无敌**，冷却 0.35 秒；**撞到的敌人受到 15 伤害并眩晕 0.3 秒**（每次冲刺每只只吃一次伤害）；用来躲爆炸怪的引信和弓箭，也能当位移输出
  - **震荡波**（60 EP）：对周围 **80px** 内的敌人造成 **20 伤害、击退 18px 并眩晕 1.3 秒**（头顶转小星），隔墙无效；用来被围时解围
- **盾反**（**不消耗 EP**，冷却 1.2 秒）：点一下开启 **0.3 秒判定窗口**（弧光也是这 0.3 秒），只对**角色前方 60° 扇形**内的攻击生效——**方向在按下瞬间锁定**（取当时的角色朝向，中途转身不会跟着变），左右各 30°，举盾时角色周围会亮起**一段 60° 的弧光**，就是可挡范围；窗口内近战、弓箭、爆炸全部免伤；近战和爆炸的出手怪会被打**硬直 0.6 秒**并**击退 14px（一格）**；**箭只要碰到这段弧光就会被原路弹回去**（方向完全反过来，不追人，箭身变青色），不必等它打到身上；来自侧面或背后的攻击挡不住
- 最远的房间有楼梯，**这间房不会刷怪**；站到楼梯上会弹出「下到第 N 层」按钮，但**必须先把本层所有刷怪房间清空**——没清完时按钮是置灰的，显示「还有房间未清理」，点了也不会下楼；清空后按钮亮起，点一下重新生成新的一层，楼层数 +1
- 每一层都用同一套规则生成（7 个房间、同样的门逻辑）；**从第 2 层起每下一层敌人都更强**：血量 ×1.22、伤害 ×1.10、击杀经验 ×1.15（复利），移速保持不变。参考：第 5 层 **2.22 倍血 / 1.46 倍伤 / 1.75 倍经验**、第 10 层 **6.0 倍血 / 2.36 倍伤 / 3.5 倍经验**、第 15 层 **16.2 倍血 / 3.8 倍伤 / 7.1 倍经验**（近战怪从 50 血 5 经验，一路涨到 809 血 35 经验）
- 左上角只显示**层数**、**HP / EP 状态条**和**等级经验条**；右上角齿轮打开设置菜单（继续游戏 / 全屏 / 返回大厅），打开时游戏暂停，`Esc` 关闭

## 操作

| 设备 | 操作 |
| --- | --- |
| 键盘 | `WASD` 或方向键移动，`J` / `空格` 射击（按住连发），`Shift` 冲刺，`Q` 震荡波，`K` 盾反 |
| 鼠标 | 按住左键射击 |
| 手机 | 左下角**固定摇杆**移动；右下角**攻击键**射击（按住连发）、**盾反键**（攻击键左侧）、**震荡键**（攻击键上方）、**冲刺键**（攻击键左上方 45°） |

## 技术说明

- 内部画布**高度 208**（宽度随窗口比例变化），像素放大不糊。
- 每个房间是 **14×14 格**（14px 一格 = 196×196 像素），边界一圈墙，门开在四面正中（两格宽）。
- 房间始终完整显示在一屏内，所以「地图变大」的表现是：**格子变多、角色相对变小**，而不是镜头拉远。
- 房间布局：从起点开始，每次随机挑一间已存在的房间往外扩一格，共 7 间；两个房间相邻就互相开门，所以布局天然连通。
- 障碍物：约 45% 的房间不放；其余的随机选一种对称方式（左右 / 上下 / 中心对称），在**中央十字外侧的环带（第 4–9 行/列）**放 1×1 或 2×2 的墙块，不贴墙边；**整间总格数控制在 3–8 格**。第 6、7 行和第 6、7 列组成的「十字」永远留空，保证出生点、楼梯和四扇门都走得通。
- 切换房间不是同一个场景里移动，而是**换一张房间地图**，把角色放到对面门口。切换时有一层黑色闪屏盖住瞬移。
- 大厅/地牢是同一个文档里的两个全屏图层，用 `hidden` 切换；未激活的那个图层会跳过绘制，省电。
- 2.5D：墙有顶面 + 正面、墙脚有接触阴影、物件按底边 Y 排序；**角色固定画在最上层，火把在地图之上、角色之下**；**门口图案属于地面细节，画在最底层**（站在门口的怪和角色会把它压住）。
- 光照只有火把：一张暗色遮罩，用 `destination-out` 在火把位置挖洞；角色本身不发光。
- **四面墙各 2 支火把**共 8 支；那一面有门时，两支会挪到门的两侧（列 5 / 8），没有门就对称放在墙中段（列 3 / 10）。

## 已知限制

- 正方形房间在横屏上两侧会留出深色岩层，这是「房间必须是正方形」的几何结果；想填满屏幕只能把房间做成横向长方形
- 手机摇杆和三个按键的手感没在真机上验证过
- 没有任何音效
